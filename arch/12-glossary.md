# Glossary

| Term | Meaning |
|---|---|
| Member | Anyone signed up and signed in. A member takes a role on each project separately. |
| Visitor | Someone browsing without signing in. |
| Idea owner | The member who created a project page and manages it. |
| Project | An idea presented on the portal, with its page, files, stages and funding ask. |
| Stage | One of the five phases a project moves through: idea, funding, prep, implementation, live. Each has a status and an expected date. |
| Live evidence | What a project in the live stage shows to prove it exists, such as a site, an app, a venue or a prototype. |
| Follower | A member who joined a project to watch it. |
| Contributor | A member who joined a project and stated how they can help. |
| Investor | A member who joined a project to pledge. Distinct from a verified investor, which is a platform-wide status. |
| Verified investor | A member whose investor verification an administrator approved; only they may pledge. |
| Pledge | An amount an investor states they are ready to invest in a project. It moves no money. |
| Concluded pledge | A pledge the owner marked as matched by a formal deal made off the portal. Neither side reverses it on the portal. |
| Pledged total | The sum of a project's pledges that are standing, concluded or not. |
| Concluded total | The sum of a project's concluded pledges. |
| Flag | A member's objection that a live project's evidence does not convince them. |
| Ruling | An administrator's decision on a flag. |
| Reliability mark | The public mark a ruling puts on an owner's account when the evidence cannot be verified. |
| Topic, thread | The units a project's forum is organised in, holding members' posts in the order they were written. |
| Administrator | A platform role that approves investor verification and rules on flags. |
